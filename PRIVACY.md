# Privacy Policy

Task Scheduler is a local-first plugin.

## Data Handling

- Task input is processed locally by the CLI or local MCP server in your environment.
- This repository does not include a hosted backend service.
- The plugin does not intentionally transmit your task data to a remote server by itself.

## Third-Party Services

- If you install Python packages from package indexes, those package downloads are handled by the tools you use.
- If you modify the plugin to connect to external systems, your privacy posture will depend on those integrations.

## Repository and Issues

- If you open a GitHub issue or discussion in the public repository, any information you share there becomes subject to GitHub's policies and your own disclosure choices.
